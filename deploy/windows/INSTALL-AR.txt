نظام إدارة المراكز التأهيلية — خطوات التثبيت على خادم Windows
=================================================================

محتويات المجلد
--------------
  setup.bat          ← المثبّت (يُشغَّل مرة واحدة)
  requirements\      ← المتطلبات: مثبّت Node.js 24 LTS (لا يحتاج إنترنت)
  dist\              ← واجهة الموقع
  server\            ← الخادم
  deploy\windows\    ← start.bat / restart.bat / uninstall.bat
  migration\         ← أداة نقل البيانات من Firebase (تُستخدم مرة واحدة)
  data\              ← يُنشأ تلقائياً: قاعدة البيانات + النسخ الاحتياطية + السجل


المتطلبات
---------
  - Windows Server 2016 أو أحدث / Windows 10 أو 11 (64-bit)
  - صلاحية مسؤول (Administrator) على الخادم
  - Node.js 22.13 أو أحدث — موجود داخل مجلد requirements ويُثبَّت تلقائياً
  - مساحة 200 ميجابايت تقريباً + مساحة للبيانات والنسخ الاحتياطية
  - منفذ 8080 (يفتحه المثبّت في جدار حماية Windows)


التثبيت
-------
  1) انسخ مجلد RehabSystem إلى القرص D ليصبح:  D:\RehabSystem
  2) اضغط بالزر الأيمن على  setup.bat  ←  Run as administrator
  3) المثبّت يقوم بـ:
       - تثبيت Node.js إن لم يكن مثبتاً
       - إنشاء مجلد البيانات وملف الإعدادات server\.env
       - إنشاء حساب المدير الأول (اضغط Enter للتخطي إذا ستنقل البيانات من Firebase)
       - تشغيل النظام تلقائياً مع كل تشغيل للخادم
       - فتح المنفذ في جدار الحماية
  4) افتح من أي جهاز في الشبكة:   http://اسم-الخادم:8080


نقل البيانات من Firebase
------------------------
  الخطوات التفصيلية في README.md (قسم «نقل البيانات من Firebase»).
  خطوة التصدير تحتاج جهازاً متصلاً بالإنترنت، ثم يُنقل الملف الناتج للخادم ويُستورد بالأمر:
     cd /d D:\RehabSystem
     npm run manage -- import migration\firestore-export.json migration\auth-users.json migration\hash-config.json
  ثم:  deploy\windows\restart.bat


الاستخدام اليومي
----------------
  إعادة التشغيل:        deploy\windows\restart.bat          (كمسؤول)
  الإيقاف والإزالة:     deploy\windows\uninstall.bat        (لا يحذف البيانات)
  سجل الأخطاء:          data\server.log
  نسخة احتياطية فورية:  npm run manage -- backup
  تغيير كلمة مرور:      npm run manage -- reset-password user@mail.com NewPass123
  تغيير المنفذ:         عدّل PORT في server\.env ثم شغّل setup.bat مرة أخرى


النسخ الاحتياطي
---------------
  - نسخة تلقائية يومياً الساعة 2 فجراً في  data\backups  (آخر 30 نسخة)
  - يُنصح بإضافة المجلد  D:\RehabSystem\data  للنسخ الاحتياطي المركزي لإدارة التقنية
  - الاستعادة: أوقف النظام ← انسخ ملف النسخة مكان data\rehab.db ← أعد التشغيل


التحديث لنسخة جديدة
-------------------
  استبدل المجلدات dist و server و deploy بالنسخة الجديدة (لا تلمس مجلد data
  ولا ملف server\.env) ثم شغّل  deploy\windows\restart.bat
